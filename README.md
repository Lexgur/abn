# ABN

Walk the number chart (1–1000) the ABN way — for children.

## Shareable builds

| Platform | File |
|---|---|
| Ubuntu / Linux | [`dist/ABN-1.0.0-linux.AppImage`](dist/ABN-1.0.0-linux.AppImage) |
| Windows | [`dist/ABN-1.0.0-windows.exe`](dist/ABN-1.0.0-windows.exe) |

No install server needed — copy the file and run it.

## Develop

```bash
export PATH="$HOME/.local/node/bin:$PATH"
npm start
npm run dist        # Linux AppImage + Windows portable
```
